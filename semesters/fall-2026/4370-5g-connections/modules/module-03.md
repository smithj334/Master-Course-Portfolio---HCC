# Module 3 — AI and Machine Learning Fundamentals for Telecommunications

## What this module is about

What machine learning actually is, in plain terms: learning patterns from data instead of following fixed rules — and where that fits in a network. A model that has seen enough examples of traffic and delay can start to predict what will happen next.

## What I worked on

- **Midterm Project, Part 3** — trained a Random Forest model on 500 simulated traffic measurements (packets per second, router load, hour of day) to predict latency. The model learned the key pattern: delay shoots up fast when a router is almost full. See [../projects/midterm/](../projects/midterm/).
- Coursework notebooks for this module are in [notebooks/](../notebooks/).

## What I took away

Machine learning is not magic, it is pattern-finding. And in a network, the pattern that matters most is that a nearly-full router delays everything behind it.
